# novapay
## Supersaving Superhero

`novapay-template-02.html` includes a **Saving Tips** button (in Money School) that opens a video of Supersaving Superhero, a cloud hero with a red mask and cape, talking about saving. The video is generated in the page (SVG, captions and optional browser speech). If a file called `supersaving-superhero.mp4` is placed next to the page, it is played instead.
